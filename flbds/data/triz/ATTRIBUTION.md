# TRIZ reference data

Parameters, principles, separation operators and the 39x39 contradiction
matrix are derived from the **MATRIZ TRIZ Knowledge Base**
(https://wiki.matriz.org), distributed under a Creative Commons licence that
requires attribution. The transcription was obtained from the MIT-licensed
`pytriz` package (https://github.com/mmysior/pytriz) and re-normalised into
`matrix.json` (39 rows = improving parameter, 39 columns = worsening
parameter, cells = inventive principle ids).

Regenerate with `python scripts/vendor_triz.py`.
